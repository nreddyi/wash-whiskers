# Wash Whiskers — Waterless Pet Care Website

Static HTML/CSS website for **Wash Whiskers**, a waterless, hand-safe and cruelty-free pet care brand.

## Versions in this repo

| Folder / file | Description |
|---|---|
| `corporate-4/` | **Newest** – playful royal-blue multi-page site (Home, About, Dog Care, Cat Care, How It Works, Guides, Contact), dogs & cats only |
| `corporate-3/` | Warm corporate one-page with hero slider, testimonial slider, scroll animations and real photos (Unsplash) |
| `corporate-2/` | Clean minimal corporate one-page (white & green) |
| `corporate/` | Corporate one-page (navy & teal, tabbed product portfolio) |
| `one-page.html` | Colourful one-page version |
| `index.html` + category pages | Colourful multi-page version (8 category pages, About, Contact) |

Open `corporate-3/index.html` in a browser to view the latest design (internet needed for photos).

Photos: [Unsplash](https://unsplash.com). Illustrations are original SVGs.
